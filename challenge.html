Challenge

Add polling to your Candidate Research skill. When you ask about a race, it should also get the latest polling average from FiftyPlusOne.

You won't write any code yourself. Your agent will look at the website, write a script called polls.py and update the skill.

I'm using on

Pick both to see the steps.

Step 1: Get your agent to write polls.py

Get your agent to write a new script, scripts/polls.py, that grabs the most recent polling average for a race from FiftyPlusOne, like this page for the Texas Senate race: fiftyplusone.news/polls/senate/general/texas.

It's up to you what to ask. Your skill is in ~/.agents/skills/candidate-research.

Step 2: Update SKILL.md

Get your agent to update the instructions in SKILL.md so the skill runs both money.py and polls.py when you ask about a race.

Step 3: Try it

Start a new chat and run:

/candidate-research Texas Senate Race$candidate-research Texas Senate Race/candidate-research Texas Senate Race

You should get the money table and the latest polling average.
