Skills with Code

A skill can come with code. The SKILL.md file tells the agent when to use the skill and how to run the code, and the code does the actual work, exactly the same way every time. That's handy for research you repeat, because the agent can't skip a step or make up a number.

We're going to add a skill called Candidate Research. It comes with a short Python script that gets campaign finance totals from the FEC: how much each candidate has raised and spent, and how much cash they have left. You can ask about a whole race, like the Texas Senate race, or about specific candidates, like Ken Paxton and James Talarico.

You'll need the FEC API key from the Setup page.

Step 1: Add the skill

  1. Open the .agents/skills folder in your home folder, where you put the greet-user skill in My First Skill.

  2. Inside skills, make a new folder called candidate-research. Inside candidate-research, make another folder called scripts.

  3. Now write the skill's instructions. Here's what goes in SKILL.md. You can change it or add your own instructions underneath:

    ---
name: candidate-research
description: Looks up 2026 campaign finance totals (money raised, money spent, cash on hand) for federal candidates using FEC data. Use when the user asks how much candidates in a race have raised, wants a fundraising update on a candidate, or wants to compare candidates' money.
---

# Candidate Research

Get the numbers by running `scripts/money.py`, which is in the same folder as this file. Don't look the numbers up any other way, and don't estimate them.

If the script says the API key is missing or wasn't accepted, stop. Tell the user to open `scripts/money.py` and paste their FEC API key on the `API_KEY` line. Don't edit the key yourself.

Step 2: Add your FEC API key

  1. Open the scripts folder, right-click money.py and choose Open With → TextEdit. (If TextEdit isn't listed, choose Other… and pick it.)

    Open the scripts folder, right-click money.py and choose Open with → Notepad. (If Notepad isn't listed, choose Choose another app and pick it.)

    Open the scripts folder, right-click money.py and choose Open With → Text Editor.

  2. Near the top, find this line:

    API_KEY = "INSERT YOUR API KEY HERE"

    Replace INSERT YOUR API KEY HERE with your FEC API key. Keep the quote marks around it, so it looks like this (with your key instead):

    API_KEY = "a1B2c3D4e5F6g7H8i9J0"

  3. Save the file and close it. While it's open, have a look around: the comments (lines starting with #) explain what each part of the script does.
