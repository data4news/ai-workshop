My First Skill

A skill is a set of instructions saved in a file called SKILL.md. DeepSeek Harness loads it whenever you ask for it, so you don't have to paste the same instructions into every chat. Every skill has two parts:

  • A description at the top, which tells the agent when to use the skill.
  • The instructions below it, which tell the agent what to do.

Let's make a "hello world" skill to see how it works. DeepSeek Harness looks for skills in a folder called .agents/skills in your home folder, so that's where yours will go.

I'm on:

  1. Open Finder. In the menu bar, click Go → Home.

    Open File Explorer. Click the address bar at the top, type %USERPROFILE% and press Enter. This opens your home folder.

  2. Press Shift + Command + . (period) to show hidden folders. Folders whose names start with a dot are hidden on a Mac, and they'll now appear faded.

  3. If you see a .agents folder, open it. If not, click File → New Folder, name it .agents (with the dot) and open it. If Finder asks whether you're sure you want a name that begins with a dot, click Use ".".

    If you see a .agents folder, open it. If not, right-click an empty spot, choose New → Folder, name it .agents (with the dot) and open it.

  4. Inside .agents, make a new folder called skills. Inside skills, make one called greet-user. (If skills is already there, just open it.)

    You should end up with:

    Home
└── .agents
    └── skills
        └── greet-userC:\Users\you
└── .agents
    └── skills
        └── greet-user

  5. Download SKILL.md, then move it from your Downloads folder into the greet-user folder. Make sure it's named exactly SKILL.md, and not something like SKILL (1).md.

    Here's what's inside. The part between the two --- lines gives the skill its name and description. Everything below it is the instructions.

    ---
name: greet-user
description: Says hello to the user. Use when the user says hello or wants to test that skills are working.
---

# Greet User

Reply with exactly this message:

👋 Hello, world! Your first skill is working.

Then, in one sentence, tell the user which file these instructions came from.

  6. Quit DeepSeek Harness (Command + Q) and open it again, so it notices your new skill.

    Close DeepSeek Harness and open it again, so it notices your new skill.

    Start a new chat, type /greet-user (or type / and pick greet-user from the list) and press Enter. You should see a Skill row appear in the conversation, followed by the hello world message.

  7. Now try it without the slash: type hello! and press Enter. The agent reads each skill's description, so it should pick up your skill on its own.

  8. Make it yours. In Finder, right-click SKILL.md and choose Open With → TextEdit.

    Make it yours. In File Explorer, right-click SKILL.md and choose Open with → Notepad.

    Change the hello message, save the file, and run /greet-user again. DeepSeek Harness re-reads the skill every time it's used, so your change shows up right away.
