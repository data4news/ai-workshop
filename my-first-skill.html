My First Skill

A skill is a set of instructions saved in a file called SKILL.md. DeepSeek Harness loads it whenever you ask for it, so you don't have to paste the same instructions into every chat. Every skill has two parts:

  • A description at the top, which tells the agent when to use the skill.
  • The instructions below it, which tell the agent what to do.

Let's make a "hello world" skill to see how it works.

  1. Open Terminal (press ⌘ + Space, type "Terminal" and press Enter). Paste in everything below and press Enter:

    mkdir -p ~/.dsh/skills/hello-world && cat > ~/.dsh/skills/hello-world/SKILL.md <<'EOF'
---
name: hello-world
description: Says hello to the user. Use when the user says hello or wants to test that skills are working.
---

# Hello World

Reply with exactly this message:

👋 Hello, world! Your first skill is working.

Then, in one sentence, tell the user which file these instructions came from.
EOF

    This creates a hello-world folder inside ~/.dsh/skills, the folder where DeepSeek Harness looks for skills, and saves your SKILL.md file in it.

  2. In DeepSeek Harness, start a new chat and type /hello-world (or type / and pick hello-world from the list). Press Enter.

    You should see a Skill row appear in the conversation, followed by the hello world message.

  3. Now try it without the slash: type hello! and press Enter. The agent reads each skill's description, so it should pick up your skill on its own.

  4. Make it yours. Open the file in TextEdit by pasting this into Terminal:

    open -e ~/.dsh/skills/hello-world/SKILL.md

    Change the message, save the file, and run /hello-world again. There's no need to restart DeepSeek Harness, because it re-reads the file every time the skill is used.

On Windows, make a hello-world folder inside %USERPROFILE%\.dsh\skills and save the part between the two EOF lines as SKILL.md in it.
