My First Skill

A skill is a set of instructions saved in a file called SKILL.md. DeepSeek Harness loads it whenever you ask for it, so you don't have to paste the same instructions into every chat. Every skill has two parts:

  • A description at the top, which tells the agent when to use the skill.
  • The instructions below it, which tell the agent what to do.

Let's make a "hello world" skill to see how it works. You'll do everything inside DeepSeek Harness, by asking the agent to write the skill for you.

  1. In DeepSeek Harness, start a new chat. Copy everything below, paste it into the chat box and press Enter:

    Create a file at .dsh/skills/hello-world/SKILL.md in this workspace with exactly this content:

---
name: hello-world
description: Says hello to the user. Use when the user says hello or wants to test that skills are working.
---

# Hello World

Reply with exactly this message:

👋 Hello, world! Your first skill is working.

Then, in one sentence, tell the user which file these instructions came from.

    The agent saves your skill in a .dsh/skills folder inside your workspace, which is one of the places DeepSeek Harness looks for skills. The part between the two --- lines gives the skill its name and description. Everything below it is the instructions.

  2. Start another new chat so DeepSeek Harness picks up the new skill. Type /hello-world (or type / and pick hello-world from the list) and press Enter.

    You should see a Skill row appear in the conversation, followed by the hello world message.

  3. Now try it without the slash: type hello! and press Enter. The agent reads each skill's description, so it should pick up your skill on its own.

  4. Make it yours. Ask the agent to change the skill, for example:

    In .dsh/skills/hello-world/SKILL.md, change the hello message to greet me in Spanish.

    Then run /hello-world again. DeepSeek Harness re-reads the skill every time it's used, so your change shows up right away.
